# Calendar-Generator - & Age Calculator Dashboard

A modern and responsive web-based dashboard built using HTML, CSS, and JavaScript that combines a Monthly Calendar Generator and an Age Calculator in a single user-friendly interface.

## Features

### Calendar Dashboard

* Generate monthly calendars for any month and year.
* Responsive calendar layout.
* Highlights the current date automatically.
* Clean and professional dashboard design.
* Smooth animations and interactive UI effects.

### Age Calculator

* Calculate age instantly by entering the birth year.
* Displays the user's age based on the current year.
* Fast and accurate age calculation.

## Project Goals

This project was created to practice front-end web development concepts including:

* DOM Manipulation
* Event Handling
* Date and Time Calculations
* Responsive Web Design
* Modern UI/UX Design Principles

## How to Run

1. Download or clone the repository.
2. Open `index.html` in any modern web browser.
3. Select a month and year to generate a calendar.
4. Enter a birth year to calculate age instantly.
